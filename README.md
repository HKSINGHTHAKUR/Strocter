## 🎯 What is Strocter?

> **Strocter** is an enterprise-grade behavioral finance intelligence platform that decodes the psychology behind spending decisions using advanced AI models, real-time cognitive analysis, and immersive 3D data visualization.

We bridge the gap between **emotional finance** and **mathematical stability** — giving individuals and institutions the tools to understand, predict, and engineer behavioral financial outcomes.

│  • Emotional States     →   • Cognitive Mapping →   • Forecasts     │

## 🚀 Quick Start

### Prerequisites

```bash
✅ Node.js v18+
✅ MongoDB Atlas account
✅ Razorpay account
✅ npm or yarn
```

### Clone Repository

```bash
git clone https://github.com/harshksingh/strocter.git
cd strocter
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

> **Frontend runs at:** `http://localhost:5173`

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

> **API runs at:** `http://localhost:5000`

### Environment Variables

#### Backend (.env)

```env
PORT=5000
MONGO_URI=mongodb+srv://your-connection-string
JWT_SECRET=your-super-secret-jwt-key-min-32-chars
RAZORPAY_KEY_ID=rzp_live_your_key_id
RAZORPAY_KEY_SECRET=rzp_live_your_key_secret
```

#### Frontend (.env)

```env
VITE_API_URL=http://localhost:5000/api
VITE_RAZORPAY_KEY=rzp_live_your_key_id
```

### Start Full Stack

```bash
# Terminal 1 - Backend
cd backend && npm run dev

# Terminal 2 - Frontend
cd frontend && npm run dev
```
